How it works

  1. A random 16-byte salt and the passphrase go through PBKDF2-SHA-256 with 310,000 iterations to derive a 256-bit key, which makes guessing passphrases slow.
  2. A random 12-byte IV is generated for every message, so the same text never encrypts the same way twice.
  3. AES-256-GCM encrypts and authenticates the message: if one byte of the ciphertext is changed, decryption fails instead of returning garbage.
  4. Salt, IV and ciphertext are packed together and Base64-encoded so they can be pasted anywhere.
