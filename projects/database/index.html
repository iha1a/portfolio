Design decisions

Integrity in the schema

Prices, ratings, quantities and order status are validated by CHECK constraints, and every relation has a foreign key, so bad data is rejected by the database itself.

Stock that can't go wrong

A BEFORE INSERT trigger rejects orders larger than the stock and decrements it in the same statement, so the application never has to remember.

Fast reporting

Indexes on the join and filter columns, and an order_totals view that keeps revenue queries short and consistent.
